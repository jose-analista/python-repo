# Python — Basic to Advanced

Repositorio de aprendizaje y demostración técnica en **Python**, organizado progresivamente desde conceptos básicos hasta aplicaciones de nivel avanzado.

El proyecto reúne ejemplos prácticos orientados a demostrar conocimientos de **programación, estructuras de datos, POO, manejo de archivos, APIs, automatización, procesamiento de datos, bases de datos y desarrollo de aplicaciones**.

## 📚 Contenido

* 🟢 **Básico:** variables, tipos de datos, operadores, condicionales, ciclos, funciones y manejo de excepciones.
* 🟡 **Intermedio:** estructuras de datos, módulos, paquetes, programación orientada a objetos, archivos, JSON, CSV y bases de datos.
* 🟠 **Avanzado:** APIs REST, automatización, web scraping, procesamiento de datos, concurrencia y arquitectura de proyectos.
* 🔵 **Aplicaciones prácticas:** ejemplos orientados a situaciones reales y pequeños proyectos para demostrar la aplicación de Python en desarrollo de software.

## 🎯 Objetivo

Este repositorio funciona como **portafolio técnico** para demostrar la evolución y aplicación práctica de conocimientos en Python, desde fundamentos de programación hasta soluciones más completas.

Está orientado especialmente a **reclutadores, empresas y desarrolladores** que quieran revisar ejemplos concretos de código, organización de proyectos y capacidad para resolver problemas mediante Python.

## 🛠️ Tecnologías

* Python
* POO
* APIs REST
* JSON / CSV
* SQL y bases de datos
* Automatización
* Web Scraping
* Procesamiento de datos
* Git / GitHub

El contenido se irá ampliando con nuevos ejemplos y proyectos prácticos.
